# EasyCapture

适用于新版 Microsoft Edge 的 Manifest V3 扩展。点击一个可滚动区域，自动从顶部滚到底部，拼接成 PNG，在新标签打开预览后下载。

## 安装到 Edge

1. 将 `easycapture-edge.zip` **完整解压**，保留里面的 `easycapture-edge` 文件夹。
2. 在 Edge 地址栏输入 **`edge://extensions`**。
3. 打开左侧的 **开发人员模式**。
4. 点击 **加载解压缩的扩展**，选择包含 `manifest.json` 的 `easycapture-edge` 文件夹。不要选择 ZIP 文件。
5. 在 Edge 工具栏的“扩展”菜单中，将“EasyCapture”固定到工具栏。

不需要运行 Python、Node.js 或网页服务。解压后的扩展文件夹请保留，浏览器需要读取它。

## 使用

1. 打开要截取的网页，点击扩展图标，然后点 **选择滚动区域**。也可以使用 **Alt + Shift + S**。
2. 移动鼠标，可滚动的整页、表格或侧栏会显示蓝框。**点击蓝框内的区域**开始。嵌套滚动区域中，按住 **Alt** 可选择外一层。
3. 扩展自动从该区域顶部开始，逐屏滚动并拼接。请保持目标标签页打开。按 **Esc** 可取消。
4. 完成后恢复原有滚动位置，并自动打开预览标签。
5. 点击 **下载 PNG**。预览里的缩放只影响查看大小，不影响下载清晰度。

动态内容加载慢时，在扩展弹窗将“滚动等待”改为 **慢速**。默认启用“避免固定栏、表头重复出现”，可在弹窗关闭。

截图较长时会按顺序分成多个 PNG，预览连续显示，并通过 **下载全部 ZIP** 一次下载。达到长度或时间上限时，预览会明确标记为部分截图。

## 本机保存与权限

- 图片在浏览器本机裁切、拼接和保存；扩展没有账号、上传接口、分析统计或外部脚本。
- 浏览器截图接口先取得可见窗口图像，扩展立即裁出所选区域，只有裁切后的图片写入本机存储。
- 点击预览里的 **删除** 可清理该截图的本机缓存，不影响已经下载的文件。
- 每次开始新截图时，清理超过 24 小时或最近 10 次以外的记录。关闭浏览器时不会自动上传或处理数据。
- `activeTab`：用户触发后访问当前标签；`scripting`：选择区域和滚动；`storage`：保存偏好；`downloads`：下载图片。没有申请所有网站的常驻访问权限。

## 支持范围

- 支持普通网页的纵向滚动，以及使用原生滚动条的表格、侧栏等容器。
- 截取当前可见宽度，不合并横向超出屏幕的内容。
- 浏览器设置页、扩展商店、内置 PDF 等受保护页面可能不允许扩展运行。`file://` 页面需在扩展详情中开启“允许访问文件 URL”。
- iframe 内嵌网页请先在独立标签打开后再截图。
- 无限加载、虚拟列表、实时变化的内容取决于网站的加载行为；可用慢速模式并在预览中检查完整性。截图最多 120 屏、3 分钟，并设有图像尺寸保护。
- 建议使用 Edge 116 或更新版本。

## 故障处理

- **点击没反应**：刷新网页，再点击扩展。检查当前是否为浏览器保护页面。
- **报切换标签错误**：截图期间保持原标签页打开，完成前不要切换或最小化浏览器。
- **预览提示缺失**：截图已被清理，重新截图即可。
- **表头仍重复**：确认弹窗里开启了固定栏去重；部分网站使用脚本模拟固定栏，可能需要手动关闭。
- **更新扩展后**：在 `edge://extensions` 点击该扩展的刷新按钮，再刷新要截图的网页。

## 验证记录

已用实际 Chromium 网页验证整页、独立滚动表格、固定表头、100%/125%/200% 缩放、超出窗口高度的容器、PNG 下载和取消后的滚动位置恢复。100%/200% 测试图中心列逐像素一致；125% 除浏览器色带边界的自然抗锯齿像素外逐行一致，接缝检查通过。超长图分段计划、ZIP 文件名、CRC 与图片字节也已核对。

当前测试环境是精简版 Chromium，不能加载原生扩展，因此浏览器扩展 API 使用本机测试桥，截图、DOM 滚动、Worker、裁切、拼接、存储和预览使用实际浏览器实现。用户已在 Edge 加载并反馈基本截图功能可用；自动回归仍使用上述浏览器接口桥接环境。
