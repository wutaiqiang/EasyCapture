EasyCapture

点击滚动区域 → 自动滚动拼接 → 新标签预览 → 下载图片。

安装，只需一次

  1. 完整解压下载的 ZIP 文件。
  2. 在 Edge 地址栏输入 edge://extensions。
  3. 开启左侧的 开发人员模式。
  4. 点击 加载解压缩的扩展。
  5. 选择包含 manifest.json 的 easycapture-edge 文件夹。
  6. 将扩展固定到工具栏。
不要直接选择 ZIP。无需启动任何命令行服务；请保留解压后的文件夹。

开始截图

  1. 打开目标网页，点击扩展图标 → 选择滚动区域。
  2. 鼠标移到表格、侧栏或整页，确认蓝框后单击。
  3. 等待自动滚动；按 Esc 可取消。
  4. 新标签打开预览，点击 下载 PNG。

默认去除重复固定栏。加载较慢的网站可在弹窗切换慢速；超长图片会分段打包下载。
